# Diwan — Website

Statische Produkt-Website für **Diwan** (diwan-sa.de): Vorstellung, Funktionen mit Live-Aufnahmen aus der App, Präsentationsvideo, Impressum, Datenschutz und KI-Hinweis.

- `index.html` — Startseite (Deutsch)
- `impressum.html` / `datenschutz.html` / `ki-hinweis.html` — Rechtliches
- `assets/` — Schriften, Video, App-Aufnahmen (lokal ausgeliefert, keine Drittanbieter-Requests)

Hosting: beliebiger statischer Host (Netlify empfohlen). Kein Build-Schritt nötig.
